# Website Client Polish Checklist

Use this checklist before sending the Talk Space website to the client for review.

## High Priority

- [x] Fix large empty whitespace before footer/contact areas. Some sections feel broken or unfinished because of excessive vertical gaps.
- [x] Improve sticky header transparency/blur. In some screenshots, content behind the nav makes it look visually messy.
- [x] Standardize image style across cards. Some images feel AI-generated, some stock-like, and one journal graphic looks very different from the rest.
- [x] Replace or refine weaker images, especially the "Beyond Silence" graphic and wedding/couple images if they do not match the therapy brand tone.
- [x] Check mobile hero cropping. The face/image crop is decent, but the text is heavy and close to the image focal point.
- [x] Fix text spacing/typos, for example `care , online` should be `care, online`.
- [x] Make CTA hierarchy clearer. "Book a session" should stay primary; phone/WhatsApp actions should feel secondary but still accessible.

## Section Polish

- [x] Hero: reduce visual darkness slightly, improve text contrast balance, and make the headline line breaks cleaner on mobile.
- [x] Brand/logo: replace generic initials with the official Talk Space logo treatment in the header and footer.
- [x] Trust bar: tighten spacing on mobile and consider making it less all-caps/heavy.
- [ ] Specialties: keep the strong layout, but make card imagery more consistent in tone, lighting, and realism.
- [x] Process section: reduce vertical padding so the dark band does not feel too tall.
- [x] Pricing section: ensure the section begins closer to the previous content and feels connected.
- [x] Reviews carousel: fix any visible cropping or misalignment, especially near the sticky header.
- [x] Journal section: keep the card layout, but make image style and article topics feel clinically/professionally curated.
- [x] Footer: reduce top whitespace before the footer and check contrast for small text.

## Before Client Review

- [ ] Test desktop, tablet, and mobile screenshots from top to bottom.
- [ ] Click every nav item and CTA.
- [ ] Confirm all phone numbers, WhatsApp links, emails, and office addresses.
- [ ] Check emergency support wording carefully since this is a therapy site.
- [ ] Run a quick copy pass for punctuation, capitalization, and tone consistency.
